## Project Overview
This project is an ASP.NET Core MVC application developed as part of the Prefinal Examination for IT Elective 2 
(Web System and Technologies). It presents a dynamic interactive dashboard containing 20 prefinal examination 
questions, multiple-choice options, correct answers, and explanations.

## Features
- **No Database Architecture:** Built entirely using in-memory C# data structures and static view models.
- **Interactive UI:** Interactive accordion view, filtering by exam topic, and dynamic score calculation.
- **Responsive Layout:** Formatted with Bootstrap cards, badges, and clean typography.
